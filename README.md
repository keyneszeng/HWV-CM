# HWV-CM｜人类三观与认知差异模型

> Human Worldview, Lifeview & Values Cognitive Model（HWV-CM）
>
> **使命：让每个人更好地理解自己、理解他人；让价值观差异不必演变成误解与伤害。**

**项目状态：v1.0.0 研究规格（2026-11-05）**。目前完成的是理论与知识库梳理、原创综合模型定义、事件分析方法和研发路线图；**尚未完成58个候选构念的心理测量学验证，也未证明 AI 调解的实际效果。**

## 1. 总体定位

HWV-CM 不是「三观打分器」或情侣匹配率工具，而是一个统一的 **个人认知 → 关系认知 → 事件分析 → 冲突化解 → 用户反馈** 系统。

- **认识自己**：持续更新由本人掌控的世界观、人生观、价值观、情绪和沟通偏好档案。
- **理解他人**：在自愿授权前提下理解共同点、差异、相互期待与边界；不默认交换私密档案。
- **处理矛盾**：按事件把事实、解释、感受、需求、诉求分开，输出可核实的假设与可执行协商方案。
- **持续改进**：只有用户明确确认的信息才可回写认知模型；从结果中评估改善程度及潜在伤害。

**统一的产品，不是两个割裂的产品。** 个人认知是底座，人际冲突辅助是应用；用户既可以先认识自己，也可以从一次现实冲突进入。

## 2. 模型 1.0：八大领域，58个候选构念

| 编码 | 领域 | 候选构念数 | 内容 |
|---|---|---:|---|
| W | 世界观 | 5 | 信任、公平、规则、不确定性、知识谦逊 |
| L | 人生观 | 5 | 意义、探索、目标、时间取向、责任 |
| V | 价值观 | 19 | Schwartz 精细化基本价值观 |
| M | 道德判断 | 6 | 关怀、平等、比例公平、忠诚、权威、纯洁 |
| P | 人格倾向 | 6 | 大五及候选诚实—谦逊维度 |
| R | 人际关系 | 6 | 依恋、边界、关系角色与互动等 |
| E | 情绪与冲突 | 6 | 情绪调节、触发、应对、升级与修复 |
| C | 情境与权力 | 5 | 角色、资源、依赖、文化规范、安全风险 |
| **总计** | | **58** | **原创整合研究框架，非现成验证量表** |

W/L/V 是三观主体；M/P/R/E 帮助解释现实互动；C 是每次事件重新分析的情境维度，不应固化为人格属性。

## 3. 科学依据与资料范围

当前汇编了 **39 项可溯源证据条目**，涵盖：
- 理论/测量：Schwartz 价值观、Big Five / BFI-2、IPIP、HEXACO、MFQ-2、SDT、MLQ、ECR-R、Gross 情绪调节、Rahim 冲突处理、APIM 等。
- 跨文化与中国本土调查：WVS、EVS、ESS、ISSP、Afrobarometer、Arab Barometer、Latinobarómetro、Asian Barometer、CGSS、CFPS。
- 研究与标准：APA PsycInfo / PsycTests、OpenAlex、AERA/APA/NCME、ITC、NIST AI RMF、UNESCO，以及适用的数据保护规范。

国际群体统计不能直接用于推断某个国籍、文化或个人的真实特征；成熟量表也不能未经许可直接嵌入商业产品。

## 4. 冲突辅助工作流

`独立同意 → 安全筛查 → 分别叙述 → 事实/解释映射 → 成因假设 → 本人确认 → 协商选项 → 自愿约定 → 结果复盘`

输出：**分歧地图**、**个性化沟通建议**、**可协商行动选项**。单人模式不能替缺席的另一方进行「读心」；发现暴力、恐吓、胁迫、严重权力不对等时，优先考虑安全与边界，不强行促成和解。

## 5. 研究及产品原则

1. 不贴永久标签，不输出未经验证的道德排名、匹配率、关系预言。
2. 所有推断都属于**待验证假设**，应当展示证据与不确定性。
3. 个人资料默认私密；关系双方分别授权、按字段共享，允许撤回与删除。
4. 事实、解释、情绪、利益和权力因素分别表示。
5. 科学验证需独立开展，比较「有画像」与「无画像」的实际效果与风险。
