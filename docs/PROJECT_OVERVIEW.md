# 项目总览：从个人认知到人际冲突化解

**项目名：** 人类三观与认知差异模型（HWV-CM）  
**版本：** 1.0（研究与产品定义）  
**日期：** 2026-11-05

## 核心问题

人与人可能因为世界观、人生观、价值观不同，对相同事件产生截然不同的解释。与此同时，现实冲突还受到情绪、沟通习惯、利益分配、角色责任、权力关系及具体情境影响。

**产品使命：** 让每个人更好地理解自己和他人，让认知差异被看见、被讨论，帮助当事人在安全、尊重和自愿基础上解决分歧。

不是要让所有人的三观趋同，也不是裁决谁“更正确”。

## 一条主线：不是两款产品

「个人认知数字档案」与「AI 人际冲突调解」是同一体系的前后环节：

1. **认识自己**：用户自愿填写量表/访谈、情境回答，生成可修正的个人认知档案。
2. **理解他人**：双方选择性共享资料，形成关系层面的共同点、差异、角色与边界地图。
3. **理解事件**：各自输入对同一事件的叙述，区分事实、争议、解释、感受、需求和请求。
4. **协商行动**：AI 给出多个待确认解释及沟通表达、妥协选项、责任和边界，决定权仍属于人。
5. **反馈修正**：当事人自愿复盘结果，动态更新个人与关系模型，避免一次性贴标签。

**研发顺序与用户使用顺序可以不同：** 开发上先建设统一底座；使用上允许用户直接从某次冲突进入，不能以长时间测评作为唯一入口。

## 统一系统的四层架构

| 架构层 | 关键对象 | 目的 |
|---|---|---|
| 个人认知层 | 世界观/人生观/价值观、道德判断、人格、情绪偏好等 | 记录长期倾向与确认的观察 |
| 人际关系层 | 共同点、冲突期待、边界、互动循环 | 描述双方相互影响，而非两组分数相减 |
| 事件理解层 | 事实、解释、感受、需求、现实利益、权力风险 | 提出可证伪的成因假设 |
| 协商反馈层 | 表达建议、协商选项、承诺、反馈 | 促进理解、允许保留差异、衡量实际结果 |

## 模型结构

HWV-CM 1.0 有 **W/L/V/M/P/R/E/C 八大领域、58个候选构念**。W/L/V 是三观主体；M/P/R/E 是解释行为和互动的辅助层；C 是每次事件重新评估的情境层。构念并非全都具备同等成熟的量表，综合模型**尚未经过实证验证**。

## 主要科学来源

- **价值观：** Schwartz 精细价值观（19类）、WVS、EVS、ESS。
- **人格与道德：** Big Five、IPIP、HEXACO、MFQ-2。
- **人生目标与关系：** 自我决定理论、生命意义、依恋、情绪调节、冲突处理、APIM。
- **文化与本土：** ISSP、非洲/阿拉伯/拉美/亚洲区域晴雨表、CGSS、CFPS。
- **方法与伦理：** AERA/APA/NCME 心理测量标准、ITC 量表适配、NIST AI RMF、UNESCO。

## 重要产品原则

- 不能用国籍、群体统计或刻板印象直接推断个体。
- 不能将 AI 对动机的猜测冒充事实；每条推断须有证据来源、不确定性和用户纠错渠道。
- 不输出「道德分数」「必然分手」「适配度86%」等伪精确指标。
- 双方独立授权，个人档案默认私密；用户可删除、撤销共享。
- 涉及威胁、暴力、跟踪、控制与显著权力不对称时，优先安全支持而非强行和解。
- 借用理论不等于取得原版量表版权/翻译版权或数据库商业再分发许可。
- 只有通过实证验证，才能逐步提出效果相关声明。
