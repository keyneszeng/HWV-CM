# HWV-CM 研究与产品研发路线图

> 本文列出拟开展的工作和验收标准，不代表这些研究、实验或软件功能已经完成。

## 阶段 A：科学基础与证据治理

| 阶段 | 工作 | 可检查的交付物 |
|---|---|---|
| R0 内容效度 | 由心理测量、跨文化心理、关系研究、冲突调解及伦理法律专家评审58候选构念 | 构念取舍、来源映射、专家反馈、风险登记 |
| R1 认知访谈 | 面向多年龄、地区、语言背景自愿参与者，验证问题是否可理解、有无偏置 | 访谈记录、题目修改、适配日志 |
| R2 小规模可行性试点 | 以约60–100名自愿参与者作为规划起点（非统计功效结论） | 用户接受度、隐私/安全测试、错误案例 |
| R3 量表验证 | 正式设计样本量与统计功效，开展结构、重测、聚合/区分效度和公平性检验 | 研究协议、分析代码、完整结果与置信区间 |
| R4 跨文化验证 | 中文普通话与英语起步，翻译/回译、认知访谈、测量不变性 | 语言适配报告、跨群体限制清单 |
| R5 双人研究 | 安全、双方自愿的配对研究，对比有/无认知画像的 AI 辅助效果 | 双方理解度、方案执行率、负面影响对照报告 |
| R6 持续监督 | 定期检查过度自信、错误归因、越界共享、控制行为及群体偏差 | 风险控制和模型修订记录 |

## 阶段 B：软件演进

### 1.1 单人研究原型
- 原创情境访谈（不是未验证却声称科学的量表）。
- 用户控制的私密档案：可编辑、删除、下载；保存来源和同意范围。
- 单人事件输入，自动拆分事实、解释、感受、需求和诉求。
- 报告中标注「自己所述」「待确认」「未知」，绝不臆断缺席方人格。
- 安全风险分流、输出审核与使用日志。

**阶段门槛：** 测试材料可追溯；所有推断可由用户修正；未出现高危隐私越界。

### 1.2 双人自愿参与试点
- 两人独立授权，明确哪些资料可共享。
- 双方叙述隔离；仅在同意范围生成联合分歧地图。
- 生成若干可协商方案，记录共同确认的约定、期限与反馈。
- 对可能存在强迫控制的关系进入安全分支，暂停联席调解。

**阶段门槛：** 权限边界和风险控制经测试与人工审查。

### 1.3 科学验证版本
- 开展 R0–R5 中相应的质量与效果验证。
- 比较相对于普通结构化沟通 AI 的**增量价值**，避免默认画像越多越好。
- 公开报告误差、样本限制、阴性结果及风险，并据此修正模型结构。

**阶段门槛：** 预先定义的质量、受益与不伤害标准达到可审计要求。

### 2.0 可推广产品
- 扩大伴侣、家庭、朋友、职场等关系类型的覆盖，逐场景验证。
- 按地区开展监管及商业许可复核。
- 在可信评估和安全机制成熟后再扩大服务。

## 当前优先队列

1. 校对39项证据的原始出处、量表及翻译版权、数据库许可。
2. 专家审查58构念的重复、遗漏与可操作定义。
3. 将18道原创访谈题拆分为可跳过的最小研究流程；拟定研究伦理与同意文本。
4. 定义私密个人记录、关系授权和事件日志的API/数据边界。
5. 构建仅用于辅助理解的单人研究原型，优先实测「事实/解释分离」和「不臆断第三方」能力。
